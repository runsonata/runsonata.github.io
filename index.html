Why use Sonata?

One command, sn, creates projects, manages dependencies, runs your code and compiles it into executables that run without Sonata installed.

extension Modular

Build your own modules and organize multi-file structured projects with ease. require("./util") loads files relative to the script, keeping your code reusable, clear, and simple to maintain.

local fs = require("@sonata/fs")
local term = require("@sonata/term")
local task = require("@sonata/task")

-- Print every entry in the current directory,
-- each one from its own task
for _, name in fs.listDir(".") do
    task.spawn(function()
        term.stdout:writeLine(term.style(name, "bold", "cyan"))
    end)
end

Install Sonata

Runs on Linux, macOS and Windows.

1
Run the install script

The script downloads the latest release for your system into ~/.sonata and adds ~/.sonata/bin to your PATH through your shell's rc file. It needs curl or wget, and tar. If Sonata needs libraries your system doesn't have (such as libsodium), it asks to install them with your package manager (apt, dnf, zypper, pacman or Homebrew).

curl -fsSL https://sonata.5418.org/install.sh | bash

No curl? Use wget -qO- https://sonata.5418.org/install.sh | bash instead.

2
Restart your shell and check that it works
sn --version
Options

Pass options after bash -s --, or set the environment variable instead:

curl -fsSL https://sonata.5418.org/install.sh | bash -s -- --version 0.1.92 --dir /opt/sonata

--version <tag>SONATA_VERSIONRelease to install, e.g. 0.1.92. Defaults to the newest release, pre-releases included.
--dir <path>SONATA_INSTALLInstall location. Defaults to ~/.sonata; sn goes in <dir>/bin.
--no-modify-pathSONATA_NO_MODIFY_PATH=1Don't add <dir>/bin to your PATH.
--yes, -ySONATA_DEPS=yesInstall missing libraries without asking.
--no-depsSONATA_DEPS=noNever install libraries; only print the command that would.

1
Run the install script in PowerShell

The script downloads the latest release into %USERPROFILE%\.sonata and adds its bin folder to your user PATH. If the Visual C++ runtime isn't installed, it asks to install it with winget or Microsoft's installer.

irm https://sonata.5418.org/install.ps1 | iex
2
Open a new terminal and check that it works
sn --version
Options

Set environment variables before running the script:

$env:SONATA_VERSION = "0.1.92"
$env:SONATA_INSTALL = "C:\sonata"
irm https://sonata.5418.org/install.ps1 | iex

Or download the script and pass them as parameters:

irm https://sonata.5418.org/install.ps1 -OutFile install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Version 0.1.92 -Dir C:\sonata

Linux / macOS

You need CMake 3.21+, a C++20 compiler, Git, zlib and OpenSSL.

git clone --recursive https://github.com/runsonata/sonata.git
cd sonata
./b.sh release
./b.sh install    # installs to $PREFIX, default ~/.local

Make sure ~/.local/bin (or $PREFIX/bin) is on your PATH.

Windows

Build in a Developer PowerShell. You need CMake 3.21+, MSVC, Git, zlib and OpenSSL.

git clone --recursive https://github.com/runsonata/sonata.git
cd sonata
cmake --preset release
cmake --build --preset release --config Release
cmake --install build/release --prefix "$env:LOCALAPPDATA\sonata"

Then add %LOCALAPPDATA%\sonata\bin to your PATH.
